挂袋区 · 轻量调试页 —— 使用说明
────────────────────────────────
打开方式：双击 挂袋区_轻量调试.html 用浏览器打开即可，
无需服务器、无需联网（纯 CSS 纸袋，全文件仅约 22KB）。
用途：专门迭代首页「最近收集」挂袋区的样式与参数，
确认满意后再统一落回主原型（袋袋集原型.html）。

页面已包含的改动：
1) 卡框：磨砂玻璃底已去掉，改为不锈钢拉丝板 + 四角 8px 螺纹
   （款式 = 全部收藏页展架两端的金属螺钉，12px 缩小版）
2) 滑轮：顶部吊耳挂钩已去掉，纯轮体，轮心正压在钢索中心线上，
   拨动时轮心沿索不动、轮体绕自身中心转（像在索上滑动）

交互：按住卡片左右拨动（带回弹阻尼）；轻点切换选中（金环）。

调参位置（改完刷新即见）：
· CSS  .rack-bags    → --rack-card-w 卡宽 / --rack-overlap 重叠 / --rack-lift 上浮
· CSS  .rack-frame   → 钢板渐变、描边、内阴影
· CSS  .rack-screw   → 螺纹尺寸（width/height 8px）、四角内缩（3px）
· JS   RACK_TILTS    → 四张卡静止微倾角度（−2°/+1.7°/−1.7°/+2°）
· HTML .swing style  → 每张卡 --dy-base 垂距（当前 0/7/14/7）

几何基准（勿轻易动，动了要同步改吊线/夹具/索位）：

夹具咬口 7.5px；钢索 2.2px，索体 top 8.88px（bags 顶部留白 60px）
