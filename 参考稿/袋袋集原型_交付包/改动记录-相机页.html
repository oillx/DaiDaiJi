点击导航栏「＋」→ 直接拉起相机页面，UI 参考设计稿 1:1 还原，图标由设计提供（3 个 SVG）。

三、实现要点

1. 层级：z-index 80

相机页是全屏覆盖层，夹在既有层级中间：

层z-index
.bottom-nav 底部导航30
.camera-screen 相机页80
.sheet-backdrop 弹层遮罩90
.bottom-sheet 弹层本体100

选 80 是为了让「拍完照 → 填名称/标签」的弹层能正常盖在相机页之上。

相机页 top: 54px 起步，正好让开原型的 .status-bar，所以状态栏依然可见（与设计稿一致）。

2. 虚线取景框用 SVG，不用 border dashed

设计稿的虚线节距实测是「19px 实 / 19px 空」，border-style: dashed 的 dash 长度由浏览器决定、不可控，所以改用 SVG：

<svg class="camera-dash" viewBox="0 0 320 363" preserveAspectRatio="none">
  <rect x="2.3" y="2.3" width="315.4" height="358.4" rx="24.7"
        stroke="rgba(255,255,255,.35)" stroke-width="4.6"
        stroke-dasharray="19 19" />
</svg>

虚线颜色是反推出来的：设计稿实测虚线像素 rgb(232,212,195)，卡片底色 rgb(219,187,161)，反解得 rgba(255,255,255,0.35)。

顺带一个坑：SVG 是 replaced element，width/height: auto 时会用内在尺寸（由 viewBox 决定），而不会被 left/right/top/bottom 拉伸。这里正好利用了这一点 —— 虚线框尺寸被钉死为设计稿值，不随卡片高度变化。

3. 闪光灯两态

两枚 SVG 同时放进按钮，靠 aria-pressed 切换显示：

.camera-ctrl .camera-ctrl__on { display: none; }
.camera-ctrl[aria-pressed="true"] .camera-ctrl__off { display: none; }
.camera-ctrl[aria-pressed="true"] .camera-ctrl__on  { display: block; }

踩过的坑：第一版写的是 .camera-ctrl__on { display:none }，结果两枚图标同时显示 —— 被上面的 .camera-ctrl svg { display:block }（特异性 0,1,1）压过了。选择器必须带上 .camera-ctrl 前缀，把特异性提到 0,2,0。

4. 与「添加收藏」的衔接

「＋」不再直接开弹层。现在链路是：

＋  →  相机页  →  快门 / 相册选图  →  画面停留 420ms
   →  关闭相机页，直接进入「添加收藏」第 2 步（填名称 / 展示架 / 标签）
  • 快门按钮驱动 <input capture="environment">，手机上会直接开后置摄像头；相册按钮驱动普通 <input type="file">
  • 两个 input 都不用 hidden，改用 opacity:0 的 1px 元素 —— 部分浏览器会拦掉 display:none 元素的 .click()
  • 取景框初始画面复用现有素材（peets-kraft），模拟「已经对准的纸袋」，与设计稿一致（不是空框）
  • 打开相机页时给 #appScroll 加 overflow:hidden，防止底层列表被穿透滚动；关闭时还原
